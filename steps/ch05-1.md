# ch05-1 · 역할별 패키지로 나누기

> 책 [5장](https://library.younggeun0.dev/react-to-spring/05) 들어가기 전 · 「앱 보충」

원서는 5장부터 별말 없이 클래스를 `controller`, `service`, `dto`, `exception`, `config` 패키지에 나눠 담는다.
그 이동만 따로 떼어 이 단계로 만들었다. 동작은 바뀌지 않는다.

```bash
git diff -M ch04-2 ch05-1 -- . ':!steps'
```

```
com/example/taskboard/
├── TaskboardApplication.java
├── controller/TaskController.java
└── service/TaskService.java
```

`TaskController`는 이제 다른 패키지에 있는 `TaskService`를 `import`한다.
두 패키지 모두 `TaskboardApplication`이 있는 `com.example.taskboard`의 하위라서, 컴포넌트 스캔이 그대로 찾아낸다. 바깥 패키지(예: `com.example.api`)로 옮기면 서버는 뜨지만 `/api/tasks`가 404가 된다([3장 4절](https://library.younggeun0.dev/react-to-spring/03#s4)의 다리 상자).

## 실행해 보기

```bash
./gradlew bootRun
curl http://localhost:8080/api/tasks
```

응답은 4장과 같다.
