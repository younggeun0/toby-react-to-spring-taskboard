# ch08-5 · DTO 프로젝션과 `@DataJpaTest`

> 책 [8장 2절](https://library.younggeun0.dev/react-to-spring/08#s2), [6절](https://library.younggeun0.dev/react-to-spring/08#s6)

원서의 네 번째 해법, DTO 프로젝션을 더하고 `summarize()`가 그걸 쓰게 했다. 그리고 그 쿼리를 원서의 `@DataJpaTest`로 못 박았다.

```java
@Query("""
    select new com.example.taskboard.UserSummary(u.name, count(t))
    from User u left join u.tasks t
    group by u.id, u.name
    """)
List<UserSummary> findSummaries();
```

```bash
git diff ch08-4 ch08-5 -- . ':!steps'
```

엔티티를 꺼내지 않고 필요한 값(이름, 개수)만 DTO로 바로 받는다. 집계는 DB가 하고, 지연 로딩도 N+1도 없다. `left join`이라 할 일이 없는 사용자도 0개로 나온다.

「앱 보충」 원서 테스트는 7장 매핑 그대로는 통과하지 않는다([8장 6절의 원문 보정 상자](https://library.younggeun0.dev/react-to-spring/08#s6)). 그래서 이렇게 고쳤다.
- `User.tasks`에 `cascade = CascadeType.PERSIST`: 사용자를 저장할 때 새 할 일도 함께 저장한다
- `User.addTask(task)`: 거울(`tasks`)과 주인(`task.user`)을 한 번에 채운다. 주인을 채워야 `user_id`가 들어간다
- `Task.setUser`, 제목만 받는 `Task(String title)` 생성자: 원서 테스트가 그대로 컴파일되게

## 실행해 보기

```bash
./gradlew bootRun
curl http://localhost:8080/api/users/summary
```

결과는 같고, SQL은 1번이다. ch08-3의 `findAllWithTasks`는 이제 `summarize()`가 쓰지 않지만, 해법끼리 비교해 볼 수 있게 리포지토리에 남겨 두었다.

```
    select
        u1_0.name,
        count(t1_0.id)
    from
        users u1_0
    left join
        task t1_0
            on u1_0.id=t1_0.user_id
    group by
        u1_0.id,
        u1_0.name
```

테스트를 돌린다.

```bash
./gradlew test --tests '*UserRepositoryTest' -i --rerun
```

`BUILD SUCCESSFUL`. `-i` 출력에서 SQL 순서를 보자. 사용자 INSERT 2번 → 할 일 INSERT 4번 → 집계 SELECT 1번이다.
할 일 INSERT는 `addTask`를 부를 때가 아니라 `findSummaries()`를 실행하기 **직전**에 나간다. JPQL을 실행하기 전에 Hibernate가 출석부의 변경을 DB에 먼저 반영(자동 flush)해서, 쿼리가 방금 넣은 데이터를 보게 한다.

`@DataJpaTest`는 기본으로 `show-sql`을 켜서 테스트 출력에는 `Hibernate: …` 줄도 겹쳐 찍힌다. `DataInitializer`는 뜨지 않아서 테스트 DB에는 테스트가 넣은 데이터만 있다.

## 직접 깨뜨려 보기: cascade를 빼면

`User.java`에서 `cascade = CascadeType.PERSIST`를 지우고 테스트를 다시 돌린다.

```
Expecting actual:
  [0L, 0L]
to contain exactly in any order:
  [2L, 2L]
```

`mappedBy` 쪽 컬렉션에 넣은 새 할 일은 아무도 저장하지 않는다. 사용자는 2명 있는데 할 일은 0개다. 확인했으면 `git checkout -- .`으로 되돌린다.
