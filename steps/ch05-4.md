# ch05-4 · 전역 예외 처리로 에러 모양 통일

> 책 [5장 4절](https://library.younggeun0.dev/react-to-spring/05#s4)

에러 응답의 모양을 `dto/ErrorResponse`로 정하고, 모든 컨트롤러의 검증 실패 예외를 `exception/GlobalExceptionHandler` 한곳에서 받아 그 모양으로 돌려준다.

```bash
git diff ch05-3 ch05-4 -- . ':!steps'
```

## 실행해 보기

```bash
./gradlew bootRun
curl -i -X POST http://localhost:8080/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": ""}'
```

```
HTTP/1.1 400

{"timestamp":"…","status":400,"message":"입력값 검증에 실패했습니다.","fieldErrors":{"title":"제목은 비어 있을 수 없습니다."}}
```

이전 단계의 `{"error":"Bad Request"}`와 비교해 보자. 프런트는 이제 `fieldErrors.title`을 그대로 입력 칸 아래에 띄우면 된다.

규칙이 여러 개 깨지면 `fieldErrors`에 필드마다 하나씩 모인다. 제목을 101자, 설명을 501자로 보내 보자.

```bash
curl -s -X POST http://localhost:8080/api/tasks \
  -H "Content-Type: application/json" \
  -d "{\"title\": \"$(printf 'a%.0s' $(seq 101))\", \"description\": \"$(printf 'b%.0s' $(seq 501))\"}"
```

```json
{"timestamp":"…","status":400,"message":"입력값 검증에 실패했습니다.","fieldErrors":{"description":"설명은 500자를 넘을 수 없습니다.","title":"제목은 100자를 넘을 수 없습니다."}}
```
