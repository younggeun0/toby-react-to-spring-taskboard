# ch10-1 · 출입증 발급기 `JwtTokenProvider`

> 책 [10장 1절](https://library.younggeun0.dev/react-to-spring/10#s1), [4절](https://library.younggeun0.dev/react-to-spring/10#s4)

원서의 `JwtTokenProvider`를 옮겼다. 토큰을 만들고(`createToken`), 토큰에서 사용자 이름을 꺼낸다(`getUsername`). 꺼낼 때 서명을 검증한다.

```bash
git diff ch09-3 ch10-1 -- . ':!steps'
```

「앱 보충」 [10장 4절의 원문 보정 상자](https://library.younggeun0.dev/react-to-spring/10#s4)대로 원서에 없는 두 가지를 채웠다.
- `build.gradle`: `jjwt-api` 0.12.6, 런타임용 `jjwt-impl`·`jjwt-jackson` 셋 다 필요하다
- `application.yml`: `jwt.secret`. 32자(256비트) 이상이어야 한다. 실습용 값이라 커밋했지만, 실제 서비스의 비밀 키는 코드에 두지 말고 환경 변수(`JWT_SECRET`)로 넘긴다

토큰을 만들어 볼 `JwtTokenProviderTest`도 더했다. 로그인 엔드포인트는 ch10-4에서 생긴다.

## 실행해 보기

```bash
./gradlew test --tests '*JwtTokenProviderTest' -i --rerun
```

```
token = eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJhcmEiLCJpYXQiOjE3OTEzNTczNTUsImV4cCI6MTc5MTM1OTE1NX0.vnVCMm7Eq_TN5FuL03SsqjnGGJFJ8nIB-ySGjtPKeFU
header  = {"alg":"HS256"}
payload = {"sub":"ara","iat":1791357355,"exp":1791359155}
```

점(`.`)으로 나뉜 세 조각이 헤더·페이로드·서명이다. 앞의 둘은 Base64URL로 인코딩만 했을 뿐 **암호화가 아니다.** 누구나 풀어 읽을 수 있다. 출력된 토큰을 [책 페이지](https://library.younggeun0.dev/react-to-spring/10#s1)의 디코더에 붙여 넣어 `sub`·`iat`·`exp`를 읽어 보자. `exp - iat`가 1800초(30분)다.

테스트 셋이 각각 확인하는 것:
- 만든 토큰을 다시 읽으면 `ara`가 나온다
- 다른 키로 서명한 토큰은 `SignatureException`으로 거부된다. 페이로드를 읽을 수는 있어도 위조는 못 한다
- 키가 짧으면 `WeakKeyException`

`signWith(key)`는 키 길이로 알고리즘을 고른다. 38바이트 키라 HS256이다(48바이트 이상이면 HS384, 64바이트 이상이면 HS512).

## 직접 깨뜨려 보기: 짧은 키

`application.yml`의 `jwt.secret`을 `too-short`로 바꾸고 `./gradlew bootRun`을 실행한다. 빈을 만들다 시작이 실패한다.

```
WeakKeyException: The specified key byte array is 72 bits which is not secure enough for any JWT HMAC-SHA algorithm.
```

확인했으면 `git checkout -- .`으로 되돌린다.
