# ch10-3 · Spring Security 6.x 방식으로 고치기

> 책 [10장 5절](https://library.younggeun0.dev/react-to-spring/10#s5)

ch10-2의 구버전 코드를 원서의 6.x 코드로 바꿨다. 이 diff가 신선도 함정의 before/after다.

```bash
git diff ch10-2 ch10-3 -- . ':!steps'
```

| before (5.x) | after (6.x) |
|---|---|
| `extends WebSecurityConfigurerAdapter` + `configure` 덮어쓰기 | `SecurityFilterChain` 빈 등록 |
| `.csrf().disable()` 체이닝 | `.csrf(csrf -> csrf.disable())` 람다 DSL |
| `.authorizeRequests()` + `.antMatchers(…)` | `.authorizeHttpRequests(…)` + `.requestMatchers(…)` |
| 정의 없는 `jwtFilter()` 호출 | 생성자로 주입받은 `JwtAuthenticationFilter` |

`sessionManagement(STATELESS)`: 서버가 세션을 만들지 않는다. 매 요청이 토큰으로 스스로를 증명한다.

「앱 보충」 원서 코드만으로는 두 군데가 모자라다.
- `JwtAuthenticationFilter`에 `@Component`([10장 5절의 원문 보정 상자](https://library.younggeun0.dev/react-to-spring/10#s5)). 없으면 시작할 때 `SecurityConfig`가 필터를 받지 못한다.

  ```
  Parameter 0 of constructor in com.example.taskboard.config.SecurityConfig required a bean of type 'com.example.taskboard.security.JwtAuthenticationFilter' that could not be found.
  ```

- `PasswordEncoder` 빈: ch10-2에서 AI 코드가 빠뜨린 것을 되살렸다. 다음 단계 로그인에서 쓴다.

테스트도 하나 고쳤다. `@WebMvcTest`는 필터 빈도 함께 올리는데, 그 필터가 `JwtTokenProvider`를 요구한다. `TaskControllerTest`에 `@MockitoBean JwtTokenProvider`를 더했다.

## 실행해 보기

아직 로그인 엔드포인트가 없으니, ch10-1의 테스트로 토큰을 하나 만든다.

```bash
./gradlew test --tests '*JwtTokenProviderTest' -i --rerun | grep "token ="
```

서버를 띄우고 토큰 없이, 토큰을 실어 각각 요청한다.

```bash
./gradlew bootRun
curl -i http://localhost:8080/api/tasks                                  # 403
curl -i -H "Authorization: Bearer <토큰>" http://localhost:8080/api/tasks  # 200
```

토큰이 있으면 200, 없으면 403이다. 왜 401이 아니라 403인지는 ch10-5에서 본다.

CSRF를 껐으니 이제 POST도 된다. 9장의 403과 비교해 보자.

```bash
curl -i -H "Authorization: Bearer <토큰>" -X POST http://localhost:8080/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": "토큰으로 만든 할 일"}'                                       # 201
```

## 남은 문제: 엉터리 토큰은 500

```bash
curl -i -H "Authorization: Bearer garbage.token.here" http://localhost:8080/api/tasks
```

```
HTTP/1.1 500
```

서버 로그:

```
io.jsonwebtoken.MalformedJwtException: Malformed protected header JSON: …
```

원서 필터는 "유효하지 않으면 예외"를 그대로 던진다. 잘못된 토큰은 서버 오류가 아니라 인증 실패다. ch10-5에서 고친다.
