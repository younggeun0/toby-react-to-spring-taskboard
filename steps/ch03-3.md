# ch03-3 · 첫 엔드포인트 `GET /api/tasks`

> 책 [3장 4절](https://library.younggeun0.dev/react-to-spring/03#s4)

`TaskController`를 추가했다. `/api/tasks`로 GET 요청이 오면 문자열 목록을 JSON으로 돌려준다.

```bash
git diff ch03-2 ch03-3 -- . ':!steps'
```

## 실행해 보기

```bash
./gradlew bootRun          # Windows 명령 프롬프트: gradlew.bat bootRun
```

로그에 이 줄이 보이면 서버가 뜬 것이다.

```
Started TaskboardApplication in … seconds (process running for …)
```

다른 터미널에서 요청을 보낸다.

```bash
curl -i http://localhost:8080/api/tasks
```

```
HTTP/1.1 200
Content-Type: application/json

["Spring 첫 엔드포인트 띄우기","커피 마시기"]
```

상태줄의 `200`, `Content-Type: application/json` 헤더, JSON 배열을 한 번에 본다. 1장에서 "서버가 정한 값"이라고 했던 것들을 이번엔 서버 쪽에서 본 것이다.
`List<String>`을 반환했을 뿐인데 JSON이 된 건 `@RestController`의 반환값을 Spring이 직렬화했기 때문이다.

## 직접 깨뜨려 보기: 포트 충돌

서버를 켜 둔 채 다른 터미널에서 `./gradlew bootRun`을 한 번 더 실행한다. Next 개발 서버처럼 다른 포트로 옮겨 뜨지 않고 멈춘다.

```
Web server failed to start. Port 8080 was already in use.
```

피하려면 `src/main/resources/application.properties`에 `server.port=8081`을 넣는다.
확인했으면 그 줄은 지우자. 이후 단계는 모두 8080을 기준으로 한다.
